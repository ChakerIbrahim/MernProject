# Sprint 09: Client UI Components

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Build reusable UI components following the design system and RTL guidelines.

## Tasks
1. Build basic inputs, buttons, and form wrappers with validation states.
2. Build data display components: `TenderCard`, `AuctionCard`, `StatusStamp`.
3. Build the `AuctionCountdown` component with light/dark variants.
4. Ensure all components use semantic colors (`bg-paper`, `text-ink`) rather than hardcoded hex values.

## Acceptance Criteria
- [ ] Components adapt to both light and dark modes.
- [ ] RTL layout utilities (`ps-`, `me-`) are used exclusively.
- [ ] Inputs show clear validation errors.
