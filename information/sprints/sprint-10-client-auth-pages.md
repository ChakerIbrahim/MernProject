# Sprint 10: Client Authentication Pages

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Implement the user-facing pages for registration, login, and email verification.

## Tasks
1. Build `LoginPage`.
2. Build `OrgRegisterPage` with file upload for proof documents.
3. Build `IndRegisterPage` with file upload for National ID.
4. Build `VerifyEmailPage` for entering the code sent via EmailJS.
5. Connect these pages to the AuthContext and backend API.

## Acceptance Criteria
- [ ] Registration flows require email verification.
- [ ] Forms have frontend validation (e.g., password confirmation).
- [ ] API errors (like "email already exists") are displayed clearly.
