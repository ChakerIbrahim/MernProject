# Archived sprint plan

This directory contains the earlier alternative MVP sprint plan that was present on the repository before the Etemad integration branch was prepared. Those files are preserved for history, but they are not part of the active plan.

The active plan is the sequential backend-to-frontend plan in `information/SPRINT_PLAN.md`, which references `sprint-00-foundation.md` and `sprint-01-server-config.md` through `sprint-20-final-polish.md`. The active sprint files describe the implementation that is now represented by the integrated source tree.

The archive is intentionally retained rather than deleted so that previous planning decisions remain reviewable. No application code is imported from this directory at runtime.
