# Sprint 19: Testing & Hardening

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Fix bugs, resolve layout alignment issues, and harden the application for production.

## Tasks
1. Verify and fix RTL alignment across all forms and cards (e.g., Auction Countdown centering).
2. Test role-based access comprehensively (Admin vs Org vs Individual).
3. Ensure the mobile layout does not overflow horizontally.
4. Verify dark mode contrast on all text elements.

## Acceptance Criteria
- [ ] No layout breakage on mobile devices.
- [ ] All inputs and buttons are easily clickable and visible in both themes.
- [ ] Security middlewares (Helmet, Rate Limiting) are active and tested.
