# Sprint 13: Client Tenders & Proposals

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Build the user interfaces for browsing, creating, and bidding on tenders.

## Tasks
1. Build `TendersPage` to list and filter open tenders.
2. Build `TenderDetailPage` to show tender info, attached documents, and the proposal submission form.
3. Build `CreateTenderPage` with AI document extraction integration.
4. Build the Proposals management view for organizations (`OrgProposalsPage`).

## Acceptance Criteria
- [ ] Users can upload an official book, and AI populates the tender creation form.
- [ ] Organizations can submit proposals with documents.
- [ ] Tender owners can view received proposals but cannot submit proposals to their own tenders.
