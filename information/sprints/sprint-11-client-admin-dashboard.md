# Sprint 11: Client Admin Dashboard

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Build the admin interface for managing users and platform activity.

## Tasks
1. Build `AdminDashboard` with overview metrics.
2. Build `AdminUsersPage` to list all users.
3. Build `AdminUserDetailPage` to review proof documents and approve/reject accounts.
4. Implement the Bento layout structure for admin navigation.

## Acceptance Criteria
- [ ] Admin can view uploaded documents for pending organizations.
- [ ] Admin can approve or reject accounts.
- [ ] The dashboard is protected and accessible only to the `admin` role.
