# Sprint 07: Client Foundation

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Set up the React frontend architecture, global state, and API communication layer.

## Tasks
1. Configure Vite, Tailwind v4, and necessary plugins.
2. Set up the `api.js` Axios instance with interceptors for attaching the JWT token.
3. Create the base HTML shell with `dir="rtl"` and `lang="ar"`.
4. Define the CSS theme variables in `index.css` (light and dark mode tokens).

## Acceptance Criteria
- [ ] Tailwind utility classes function correctly.
- [ ] Axios automatically attaches the token to outgoing requests.
- [ ] The app renders a basic layout without errors.
