# Sprint 14: Client Auctions & Bidding

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Build the user interfaces for live auctions and real-time bidding.

## Tasks
1. Build `AuctionsPage` to list active auctions with countdown timers.
2. Build `AuctionDetailPage` showing product specs, bid history, and the bidding control panel.
3. Build `CreateAuctionPage` with AI product specification extraction.
4. Ensure the layout places the bid log alongside the bidding controls for easy access.

## Acceptance Criteria
- [ ] Auction cards display a centered, light-mode countdown timer.
- [ ] Users can place bids, and the UI updates the current price.
- [ ] Auction owners cannot bid on their own auctions.
