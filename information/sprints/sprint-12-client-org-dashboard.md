# Sprint 12: Client Organization Dashboard

**Prerequisite:** Read every document in `/information` before starting.

## Goal
Build the dashboard and profile pages for organization users.

## Tasks
1. Build `OrgDashboard` with quick actions and metrics.
2. Build `OrgProfilePage` to view/edit organization details.
3. Implement the side navigation rail for desktop and bottom sheet for mobile.
4. Apply conditional rendering based on the organization's approval status (e.g., pending review).

## Acceptance Criteria
- [ ] Unapproved organizations see a restricted dashboard with status alerts.
- [ ] Navigation is responsive (sidebar on desktop, drawer/menu on mobile).
